# 《Le Comptoir de Marthe》 프랑스어 연속 대화문 기획서

파리 11구의 작은 가족 비스트로 "르 콩투아르 드 마르트"의 1년 반. 평온한 봄, 균열이 시작되는 여름, 벼랑 끝의 가을, 다시 일어서는 겨울, 성공 뒤의 새로운 시험까지.
프랑스어 낭독 말하기 연습용 연속 대화문 (한글 해석 + 어휘·문법·표현 분석 + 낭독 포인트 포함).

---

## 3-1. 문체 원칙: 구어 중심

낭독으로 실제 말하기를 연습하는 것이 목적이므로 **대화는 실제 프랑스인이 말하는 구어(registre courant)** 로 쓴다.

| 항목 | 원칙 |
|---|---|
| 기본 문체 | 일상 구어. 문어적 문형(접속법 반과거·대과거, 단순과거, 과도한 도치)은 쓰지 않는다 |
| 구어 특징 | `ne` 생략(*Je sais pas*), `on`(= nous), `tu`/`vous` 구분, 축약(*t'as, y a, j'sais*), 생략문, 문장 끝 확인(*hein, non ?, quoi*) |
| 담화표지 | *ben, bah, enfin, alors, du coup, en fait, bon, tiens, écoute* 등을 자연스럽게 배치 |
| 어휘 층위 | 손님 앞은 정중한 vous, 주방 안은 tu와 가벼운 속어(*bouffe, boulot, galère* 수준). 비속어는 제외 |
| 격식이 필요한 장면 | 은행, 법원, 검사관, 호텔 지배인 장면은 정중한 vous로 하되 **문어가 아닌 정중한 구어**. 공문과 청원서는 짧게 낭독하고 곧바로 구어로 반응 |
| 연설·독백 | 은퇴 연설 등은 문장을 짧게 끊고 구어 리듬을 유지 (*Alors voilà…* 식) |
| 분석 표기 | 구어 표현에는 `[구어]` 태그를 붙이고, 같은 뜻의 정중한 표현을 옆에 비교 제시 |
| 문장 길이 | 한 호흡 15단어 이내를 기본으로 하고, 긴 설명도 두세 덩어리로 나눈다 |

## 4. 화별 구성 템플릿

1. **헤더**: 제목 / 장소 / 어휘 영역 / 학습 포인트 / 낭독 포인트
2. **대화문 120턴** (지문은 *이탤릭 괄호*로 최소화)
3. **주요 단어·표현 분석**: 약 15~20개, 레벨 태그 `[A2]` `[B1]` `[B2]` `[C1]`, 구어 표현은 `[구어]`, 재등장 시 `(복습)`
4. **문법 분석**: 5~8개, 대화 속 실제 문장 인용
5. **문화 메모**: 1~2개 (프랑스 외식·노동·행정 문화)
6. **한글 해석**: 맨 마지막에 대화 순서대로 전부 수록
7. **다음 화 예고** 한 줄

### 낭독 장치
- 120턴을 **30턴 단위 4막**으로 나눠 연습 단위를 제공 (막마다 감정 곡선 하나)
- 홀·주방의 빠른 지시(짧은 문장)와 손님 응대(긴 문장)를 섞어 **속도 조절** 훈련
- 화마다 난발음 목록(예: *rue, tu, vous, un, bien, boeuf, oeufs, fruits de mer*)을 의도적으로 반복 배치

## 6. 전체 스토리 아크 및 화별 개요

### 제1부 — Mise en place (봄, A2~B1) — 평온한 식당의 일상
위기 없이, 식당에서 일어나는 다양한 일을 폭넓게 다룬다. 현재형, 복합과거, 기초 질문·주문·숫자·정중한 요청 중심.

## 7. 학습 설계 메모

- **문법 로드맵**: 1부 현재·복합과거·명령형 → 2부 조건법·접속법 입문·대과거·간접화법 → 3부 접속법 심화·수동태·조건법 과거 → 4~5부 양보·가정 종합. 모든 부에서 구어 표현(축약, 생략, 담화표지)을 병행.
- **어휘 반복 장치**: 같은 인물과 장소가 계속 나오므로 식재료·서비스 표현이 부를 넘어 복습되고, 1부의 일상 어휘가 3부에서 감정 대비 효과로 다시 쓰인다.
- **감정 곡선**: 1부(안정) → 2부(불안) → 3부(절망과 결단) → 4부(재건) → 5부(성공과 상실, 성숙). 낭독 시 목소리 톤과 속도 변화를 훈련하기 좋게 설계.
- **1부 설계 원칙**: 위기를 미리 암시하지 않고 평범한 하루를 충실히 그린다. 15화의 마지막 장면에서만 복선을 놓는다.
- **부 간 연결**: 각 부 마지막 화는 클리프행어 또는 결정으로 끝내 다음 부로 이어진다 (15, 30, 45, 60화).
