# 베를린 서점 시리즈 – 진행상황 & 연속성 메모 (재개용)

> 이 파일은 세션이 중단(사용량 한도 등)되어도 작업을 이어가기 위한 단일 기준 문서입니다.
> **재개 방법:** 아래 “다음 작업” 항목부터 한 화씩 만들고, 매 화마다 검증→커밋→푸시→이 파일 갱신.

## 요청 사양 (사용자)
- 독일 베를린 서점에서 만난 베를린 출신 30대 중반 남녀가 연인이 되어 가는 과정을 **독일어 대화문**으로.
- 4부 × 12화 × **각 화 100턴**. (현재 진행: 1부 완료, 2부 진행 중, 3부 계획)
- 난이도 A2~B2 혼합, 때로는 그 이상. **턴 번호 넣지 않을 것.** 다양한 주제.
- **주요 단어·표현·문법을 한국어로 설명.**
- 사용자 요청: “2부에서 3부 끝까지 만들고, 세션 사용량 한도로 중단되면 한도가 리셋될 때 자동으로 이어서 작업.” (4부는 아직 요청 없음)

## 파일 형식 규칙 (모든 화 동일)
- 경로: `베를린_서점/{N}부/{N}부_{M}화_{독일어제목}.md`
- 머리말: `# {N}부 {M}화 · 독일어 제목 (한국어 제목)` → 배경/인물/난이도/이전 줄거리 → `---`
- 4개 장면: `## Szene 1 – … (한국어)` … 각 장면 **정확히 25턴** (총 100턴, 교대로 말하기, 화자 라벨 `**Lena:**` `**Jonas:**`, 빈 줄로 구분, 턴 번호 없음)
- 각 장면 뒤 `### 📚 Szene N 해설` : **주요 단어**(표) / **주요 표현**(목록) / **문법 포인트**(번호 목록, 한국어 설명)
- 마지막에 `## 📝 N부 M화 전체 정리` : 핵심 문형 12개, 문화 노트, 다음 화 예고
- 제3자(조연)는 대사 없이 등장하고 두 주인공이 그들의 말을 전달(직접·간접화법/접속법 I 연습).
- 검증: `python3 베를린_서점/도구/check.py <파일>` → `100 True <첫화자> <끝화자> [25, 25, 25, 25]` 이어야 함.
- 워드 변환: `python3 -I 베를린_서점/도구/build_docx.py 1부 "베를린 서점 1부 (1화-12화)"` (결과: `베를린_서점/워드/`). 부가 끝날 때, 그리고 최종 완료 시 갱신하고 `SendUserFile`로 전달.
