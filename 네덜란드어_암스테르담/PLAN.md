# 《Het Hoekhuis》 네덜란드어 연속 대화문 기획서

암스테르담 요르단(Jordaan) 지구 운하 모퉁이의 4층 건물. 1층 브라운 카페 't Hoekje와 위층 세입자들의 1년 하고도 한 계절.
네덜란드 사람들끼리 나누는 실제 구어를 낭독으로 연습하기 위한 연속 대화문 (한글 해석 + 어휘·문법·표현 분석 + 낭독 포인트 포함).

> 레벨(A2~C1)과 화당 턴 수(120)는 프랑스어 시리즈(Le Comptoir de Marthe)와 같은 기본값이며, 엑셀의 입력 칸에서 바꿀 수 있다.

## 3-1. 문체 원칙: 구어 중심

네덜란드 사람들끼리 나누는 **실제 구어(spreektaal)** 로 쓴다. 책에 나오는 문어체 문장은 쓰지 않는다.

| 항목 | 원칙 |
|---|---|
| 기본 문체 | 일상 구어. 암스테르담 억양과 어휘를 반영하되 표기는 표준 철자를 따름 |
| 구어 특징 | 축약(*ik heb 'm, 't is, d'r, zo'n, m'n*), 생략문, 문장 끝 확인(*hè, toch, of niet, zeg*) |
| 담화표지 | *nou, ja, hoor, even, gewoon, eigenlijk, joh, man, tja, hè, zeg* 등을 자연스럽게 배치 |
| 호칭 | 친구·가족·동료는 *je/jij*, 노인과 격식 장면(은행, 변호사, 투자회사, 공무원)은 *u*. 호칭 전환 장면을 의도적으로 넣음 |
| 어휘 층위 | 카페와 가족 사이는 생생한 속어 (*balen, kut-weer, lekker, tof, knap, joh, aanstellerij*) |
| 거친 표현 | 압박과 다툼 장면에서 *shit, verdomme, godverdomme, klote, kut, tering* 정도까지 허용. 질병을 이용한 저주와 모욕·차별·성적 표현은 제외. 격식 장면과 아이 앞에서는 쓰지 않음 |
| 감정 폭발 | 3부 위기와 가족 다툼에서 말 끊기, 소리침, 중얼거림 등 날것의 구어 리듬을 살림 |
| 학습 안전장치 | 거친 표현은 `[속어]` 태그로 구분하고, 분석에서 쓸 수 있는 상황과 쓰면 안 되는 상황을 한 줄로 명시 |
| 문장 길이 | 한 호흡 15단어 이내를 기본으로 하고, 긴 설명도 두세 덩어리로 나눈다 |
| 지명·고유명 | 현실 지명과 행사(킹스데이, 신터클라스 등)는 실제 문화를 반영하되 인물·업체·사건은 모두 허구 |

## 4. 화별 구성 템플릿

1. **헤더**: 제목 / 장소 / 어휘 영역 / 학습 포인트 / 낭독 포인트
2. **대화문 120턴** (지문은 *이탤릭 괄호*로 최소화)
3. **주요 단어·표현 분석**: 약 15~20개, 레벨 태그 `[A2]` `[B1]` `[B2]` `[C1]`, 구어 표현은 `[구어]`, 거친 표현은 `[속어]`, 재등장 시 `(복습)`
4. **문법 분석**: 5~8개, 대화 속 실제 문장 인용
5. **문화 메모**: 1~2개 (네덜란드 생활·행사·사회 문화)
6. **한글 해석**: 맨 마지막에 대화 순서대로 전부 수록
7. **다음 화 예고** 한 줄

### 낭독 장치
- 120턴을 **30턴 단위 4막**으로 나눠 연습 단위를 제공
- 화마다 난발음 목록(예: *g/ch, schrijven, uitgaan, huis, nieuw, eeuw, lekker, hoeveel*)을 의도적으로 반복
- 카페의 빠른 구어와 격식 장면의 느린 u-화법을 섞어 **속도와 어조 조절** 훈련

## 7. 학습 설계 메모

- **문법 로드맵**: 1부 현재형·V2 어순·조동사·분리동사·완료시제 → 2부 조건법(zou)·관계절·간접화법·수동태 입문 → 3부 접속사 어순(omdat/dat 등)·er 용법 심화·격식 화법 → 4~5부 협상·발표 화법, 가정문, 복문 종합.
- **호칭 전환 훈련**: je(친구·가족)와 u(은행, 변호사, 투자회사, 시청, 공증인)를 한 부 안에서 번갈아 쓰게 해 전환 감각을 기른다.
- **발음 훈련**: g/ch, ui, eu, ij/ei, sch, oe/uu를 화마다 주제 단어로 반복하고, 3~4막으로 나눈 낭독 단위를 제공.
- **감정 곡선**: 1부(일상) → 2부(소문과 불안) → 3부(위기와 폭발) → 4부(연대와 협상) → 5부(결과와 정착).
- **부 간 연결**: 각 부 마지막 화는 클리프행어 또는 결정으로 끝난다 (15, 30, 45, 60화).
