# 《Das Eckhaus》 연속성 메모 (집필 중 확정된 사실)

## 형식
- 원고: `원고/N부/epNN.txt` → `tools/commit_ep.sh 원고/N부/epNN.txt "커밋 메시지"` (빌드·기획서 상태 갱신·커밋·푸시)
- 화당 정확히 120턴. 장면 6개 × 20턴 기본. 각 화: #read(낭독 포인트) 4~5개, #note(표현 노트) 4~6개.
- 독일어 층수: zweiter Stock = 한국식 3층.

## 시간
- 1부 = 2026년 3월~5월. 1화 3월 초 화, 2화 3월 중순, 3화 3월 하순, 4화 4월 6일 부활절 월요일, 5화 4월 13일(방학 후 첫날), 6화 4월 17~18일, 7화 4월 하순 토, 8화 4월 말 월, 9화 5월 초 토, 10화 5월 초 월(휴무일).

## 건물·장소
- 마이바흐우퍼 모퉁이 알트바우, 1908년 건축. 지하 창고 14개 + 뒤쪽 빈 큰 방. Vorderhaus / Seitenflügel / Hinterhof.
- 집주인: 옛 주인 벤트(Herr Wendt) 씨가 2년 전 사망 → 자녀 셋의 상속인 공동체(아무도 베를린에 안 삶). 관리회사 „Kiez Hausverwaltung GmbH"(허구). 이메일 답 없음.
- 건물 현관문(안마당 쪽) 자물쇠 고장 몇 주째(2화~9화). 관리인 피치(Herr Pietsch) 씨 1년 전 은퇴, 그런데 관리비에 관리인 비용 310€ 청구됨 → 슐체 부인이 이의 신청.
- 크나이페 „Zur Ecke": 월요일 휴무. 칠판(Kreidetafel). 카드 결제 작년부터. 점심 메뉴 „Eckteller": 커리부어스트+감자튀김/빵 7,50 / 불레테+감자샐러드 8,50 / 렌틸콩 불레테 8,50 / 수프 6,50(수 솔랸카 „nach Monika", 금 감자 수프). 커피 2,50, 필스 3,80.
- 칼레는 2008년 우니온 경기장 공사에 토요일 세 번 참여. 개업 25주년이 다가옴(17화).

## 인물 확정 사항
- 칼레: 사별. 아내 모니카(리히텐베르크 출신, 솔랸카가 최고). 야나에게 부활절 달걀을 쓰레기통 뒤에 숨기곤 함.
- 야나: 커피 블랙(3년째). 공휴일에도 사장 전화 받음. 동료 절반이 채식.
- 에디트: 1943년 4월 18일 베딩 출생. 1974년 3월 1일부터 Seitenflügel 4층(3. OG), 방 2개, 월세 390€ → 7월부터 448,50€(+15%, Mietspiegel). 계단 78개. BVG 버스 기사 25년(19번, 29번 노선). 남편은 18년 전 사망. 언니 기젤라(86세, 3살 위) 코트부스 요양원, 조카딸 카린, 조카손주 루카스(15). 1989년 언니가 준 목걸이를 매일 함. 47번째 생일(1990년 4월)이 가장 행복했음. 여름에 코트부스 방문 약속(파울 동행 가능성). 생일 전 축하 금기.
- 데르야: 간호사, 병동 인력 2명 부족, 근무 교대 자주. 집 68㎡ 방 3개, 기본 월세 720€(인덱스 임대, 2021년 계약) → 7월부터 +17,28€. 관리비 추가 납부 412€(5월 말까지).
- 잔: 5b반. 생일 선물(할아버지) 파란 자전거·노란 타이어 2화에 도난. 토비와 낡은 자전거 수리 중. 6월 우제돔 수학여행(280€, 4월 말·5월 말 분납). 돼지 저금통 46€. 수학 수업 3주째 결손.
- 할아버지 휘세인: 베를린 50년, 공장에서 계산이 제일 빨랐음, 자전거 세 번 도둑맞음(한 번은 모스크 앞). 잔은 „Dede"라고 부름.
- 토비: 부모님 슈판다우. 고기 거의 안 먹음(칼레 불레테만 예외). 할아버지의 20년 된 우니온 목도리.
- 슐체 부인: 세무서 30년 근무. 9년 전 이혼, 그 뒤로 크뤼멜(수고양이, 줄무늬, 흰 발 4, 초록 목줄, 왼쪽 귀 접힘, 통통). 매일 8시 우편함. 치즈케이크 12조각(어머니 레시피). 파울 번호를 받음(소음 시 문자).
- 파울: 막스네(Seitenflügel 3층=zweiter Stock) 소파. 전입신고 안 함. 문의 30군데 무응답. 에네르기 코트부스 팬.
- 막스: 29세, 취미 DJ. 칼레가 토요일에 크나이페에서 틀게 해 주겠다고 제안(3화).
- 비네: 아들 핀(18, 헤르타 팬, 아비투어 수학 시험 5월, 진로 미정). 핀 아버지는 샤를로텐부르크 출신(이혼 여부 미언급).
- 학부모: 자드라 베커(학부모 대표), 민 응우옌(딸 린, 식당 운영) — 데르야와 du.
- 에디트와 기젤라: '예전에 담장 앞에서(am Zaun)' 이야기하던 기억 → 34화(1961) 회상에서 설명할 것. 에디트는 자식·손주 없음. 친구 하넬로레가 작년 전화 사기로 3,000€ 잃음. 에디트 중고폰(존넨알레) 11화부터 왓츠앱 사용.
