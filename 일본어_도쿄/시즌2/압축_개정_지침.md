## 2. 연동 사건 날짜
- 아베 USB 복사: 1/9 23:04 → **6/29(토) 23:04**. 지토세역 분실: 1/10 → **6/30**. 하야카와 도쿄(저우 면담): 1/10 → **6/30**.
- 하야카와·렌 오스틴 파견: 1/20 출발 ~ 3/29 귀국 → **7/9 출발 ~ 8/9 귀국**. 나가오카 방문은 귀국 다음 날(8/11 전후로 맞출 것).
- 저우의 답변 기한 "3월 말" → **"8월 10일까지"**. 싱가포르 자리 "4월부터" → "9월부터".
- USB 발견: 공항 3/4, 경찰 이관 3/9 → **7/25 발견, 7/28 이관**. "53日" → **"二十六日"**(6/30→7/26 기준으로 맞출 것). CCTV 2주 보존 "2/18より前" → **"7/14より前"**.
- 銅密度表_v3 마지막 접근 2/26 14:12 → **7/22 14:12**(규칙 회의 다음 날). v3 = "작년 12월판" → **"5月の版"**, v5 = "2월 재작성" → **"7月に作り直した"**. "설계가 1월에 바뀜" → "6월에".
- 정보 관리 계획 제출 기한/제출일, 노구치 첫 방문(3/28) → 8/9 전후로.
- 나가오카 분실 개시 5/7 → **8/19**. 하야카와 부친 '수요일 보는 눈'.
- 2호기 두 번째 대 반입 4/7 → **8/18**. 하노이 개원 4/14 → **8/26**.
- 저우의 나가오카 '헤기소바 사용료' "5월" → **"9월 7일"**.
- 지토세 HB 양산 개시 6/2 → **9/12**. 서랍 기록 "3월부터 오늘까지 412회" → "8월부터 오늘까지" (횟수는 기간에 맞게, 예: 약 150회). 3부12의 "6월부터 12월 908회" → "9월부터 12월" (예: 약 400회).
- 가시와기: 첫 대면 지토세(9/12), 가마타 방문 9/17. "七月から" → "九月から", "八月に、電話" → "九月に". 히무로 공개 청구는 9월 말 청구 → 10월 하순 수령.
- 지주회 의견 모임 "8월" → "10월". 첫 시험 창 "8월 8일" → "10월 11일".

- 구로사키: 2030년 6월(주주총회) 상무 퇴임. "去年は、まだ、常務" → "六月までは、常務". "去年、鷹野くんに手伝うと言った" → "六月に". 1부15의 "연내 퇴임/오늘로 상무 퇴임/종무일" 표현 수정.
- 히무로: 2030년 새해부터 나가오카(사쿠마 주조 재건). 3부7의 "三年目" → **"まだ、一年目"**, "二年目の、冬に、一回、踏んだ" → **"春に、一回、踏んだ"**(눈에 미끄러짐 → 다른 이유로).
- 1부1의 "오스틴·하노이 2031년 봄" → **"今年の、夏"**. 1부13 "来年の、春。半年。" → **"この、夏。二か月。"** 등. 1부 안의 "来年" 중 2031을 가리키는 것은 "今年の秋/夏"로.

## 3. 경과 시간·연호 (2031 → 2030 이므로 대부분 1 줄어듦)
- 겐 씨 근속 1973~: 五十八年 → **五十七年**. 3호기(1979~): 五十二年 → **五十一年** ("五十二年前、祖父が日曜に来た" → 五十一年前).
- 1986 메모: 四十五年前 → **四十四年前** (45년 뒤의 누군가 → 44년).
- 1998 산에이: 三十三年 → **三十二年**.
- 1973 선대 조준기 거절: 五十八年前 → **五十七年前**.
- 2011 동일본: 二十年前 → **十九年前**.
- 2023 방위 생산 기반 강화법: 八年前 → **七年前**.
- 야마토 4,600개 사건(2026): "四年前"은 2030 기준으로 맞으므로 **그대로**. S1 컨소시엄·국가의 재산(2027): "四年前" → **"三年前"**.
- 히사고 선대 자리 열칸: "六十年" → **"五十九年"**.
- 令和十三年 → **令和十二年**.
- "去年"/"今年"/"来年": 2부·3부에서 2030년 1부 사건을 가리키던 "去年" → "今年" 또는 "春に/一月に" 등. 3부의 "来年"(2032)은 "来年"(2031) 그대로 두되 내용이 맞는지 확인. 3부15 "二年前の一月六日" → "今年の、一月、六日", "この二年" → "この一年", 구로사키 "二年前の暮れ" → "去年の暮れ".
- 2부15/3부12 가사이 시계 농담: 2부15는 葛西 "去年のことのようだ" → 鷹野 "今年の一月です" → 葛西 "私の、時計は、もう、一年、進んで、いる" 식으로, 3부12 "今日、時計が、合った"는 "一年 진행된 시계가 오늘 실제로 1년이 됐다"로 맞출 것.
- 3부13 매출 증가: "前の年より一割" → **"二割"**. 지주회 2% 양도는 "今年、二度目。三月と、十二月" 취지로, "定年の日に…から二年" → "定年の、春から、九か月".
- 3부14 "早川さんの、二〇三〇年の、論文" → "早川さんの、春の、論文"(1부 설정과 맞출 것).

## 5. 계절 묘사
- 2부(7~9월)는 여름. 쓰바메·나가오카·가마타의 추위·눈 묘사, "厚着" 농담(저우, 2부10·14) → 더위 표현(예: "日傘" "東大阪の子は暑さには強い")으로.
- 2부3 오스틴 습도 18%의 이유: "텍사스 겨울의 건조" → **"클린룸 공조가 여름 습기를 너무 빼서 18%"**로. 가습 40%로 7분 복귀는 그대로.

- 하노이 8월: 덥고 비. 박닌 공장 "去年の秋から建設、来年春稼働"은 유지 가능.
