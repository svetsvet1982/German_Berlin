- S2 1부 2화(2030/1/15~25): 가사이 칩 10개 직접 지참(시제품 1개 20만 엔, 8mm 각, 한 면에 구리 전극 1만 개). 겐 씨 확대경 「銅が、島のように、浮いてるな。灰色の、海の、中に」(절연막=유리 친척). 첫 연마: 절연막 0.3nm·구리 12nm 패임(디싱). 하이브리드 본딩은 구리가 약 2nm 패여 있는 게 좋음(절연막끼리 상온 접착 → 가열로 구리 팽창해 틈 메움), 「へこみすぎても、だめ…でっぱっても、だめ」. 힘으로는 둘 다 못 세움 → 연마액 화학(구리 보호막 약품) → 슈이치 "구리를 붙이는 게 도금, 깎는 게 연마, 같은 구리 얘기" → 미요시 도금 사카모토(64)·다쿠미(25) 「抑制剤」, 선대 미요시 사장 칠판 배합에 온도별 억제제 표(30년 전), "구리 화학은 온도로 전부 바뀐다"(작년 여름 73번 3도 실패), "논문 쓰는 사람은 도금 조 앞에 서 본 적이 없다". 구리판·유리판으로 먼저 20조건(온도 5×약품 4) → 25도·약품 3번째: 구리 2.1nm·절연막 0.3nm(도금 표와 같은 온도). 다쿠미 "온도계 두 개". 가스가 입사 4년째(슈이치 '재미있다' 얼굴에 이미 전화). 겐 씨 "작은 건 팔꿈치보다 손가락, 손가락 바닥으로 쓰다듬어라, 누르지 마". 칩 10개(란 5·겐타 5) 평균 2.2nm, 겐타 쪽 가장자리 패임 적음. 5쌍 접합(위치 0.2μm 이내) → 가마타 열처리 우다가와 유타카(61, 열처리 40년, 1월 네트워크 가입) 200도 2시간·±2도·승온 분당 5도(급가열 시 유리·구리 팽창 차로 깨짐), 겐 씨 「磨くより、待つほうが、難しい」. 결과: 1~3쌍 1만/1만 통전, 4쌍(란+겐타 칩) 모서리 800개 불통, 5쌍(란 칩 2개) 중앙 원형 2천 개 불통(보이드=먼지 추정) → 6할, 가사이 "양산이면 불합격(99% 필요), 첫 시제작으로는 본 것 중 최고". 원인 2개로 분리(모서리=연마, 중앙=세정) 「原因が、分かれたら、半分、解けた」. 다음: 300mm 웨이퍼(칩 900개)째 연마·접합, 클린룸, CMP 장비(대당 몇억). 겐 씨 "기계한테 손가락 바닥이 있냐" → 에토 "겐타 손가락 압력 데이터로 만들 수도" → 「なるんじゃねえ。教えるんだ」. 사카모토 도금 칠판 옆에 연마액 표 덧쓰기 → 미요시 씨 허락 먼저.
- S2 1부 3화(2030/1/29~2/9): 300mm 연습용 웨이퍼(칩 900개), 겐 씨 「鏡の、皿だ」, 3호기 최대 100mm(면적 9배), "손으로는 무리, 내가 말하니 틀림없다". 가사이 3개의 벽: ①방(클린룸, 1세제곱피트 먼지 수십만 → 100개 이하, 최소 1,000㎡, 전기료) ②기계(CMP 2대 + 접합 장비 1대, 접합 장비 제조사는 세계 2곳 모두 유럽, 납기 1년 반) ③사람(CMP를 손처럼 다루는 사람, 대기업이 다 안고 있음). 신축 시 30억(작년 매출 1.5배). 가사이 제안: 넥스트실리콘 후공정동 3층 동쪽 빈 구획 + 장비 넥스트 구매 후 대여 → 10억 이하·장비 반년 단축 → 단 건물 규칙 준수, 타 반도체사 웨이퍼 취급 곤란 → 슈이치 「全部の、卵が、一つの、かごに、入る」(야마토 4할보다 깊은 바구니). 지토세(영하 10도): 2기생 20명 전원 잔류, 2기 반장 아베 미즈키(20, 하마나카초 다시마 어가, "아버지는 늘 스스로 값을 못 정한다 → 내 손으로 값을 정하는 일", 2기생 중 모서리 제일 깨끗, 겐타와 닮음, 가사이 새해 다시마가 고향 것일지도). 3층 구획(기준 충족) vs 연마 학원 옆 빈 땅 2동(1층, 선대와 같은 3배 콘크리트+말뚝) → 30억·1년 반 감수 「自分の、床の、上でしか、自分の、値段は、決められない」 → 가사이 구획 철회, 장비 주문은 넥스트 순번을 다카노 이름으로 양보("바구니엔 안 넣는다"). 렌 "2동 서면 손과 기계가 이웃". 에토 연구실 200mm 연구용 CMP(헤드 5개 고리 영역): 겐타 손가락 바닥(가장자리를 약하게) → 100·98·96…88 → 가장자리 패임 6→2.3nm, 그러나 가운데 1.0nm(부족), "하나 움직이면 전부 움직인다"(고리 5·속도·온도·약품·패드 경도), 에토 "원리는 알지만 양산 기계는 매일 돌려 본 적 없다". 겐 씨: 3호기 첫 3개월 매일 망가뜨릴 뻔 → 메이커 젊은 기술자가 일요일마다 회사 몰래 와서 기계 버릇을 가르쳐 줌 「機械にも、癖が、ある。手と、同じだ」. 하야카와 마코토(34, 대형 장비 메이커 CMP 헤드 설계, 웨이퍼 가장자리 깎임 논문으로 작년 수상, "사람 손은 재현성 없다, 전부 기계로"). 시즈에: 선대도 3호기 때 메이커 계열 편입 제안 거절 「床は、自分で、打つ」 → 3년 빚, "그땐 아무도 안 도와줬지만 지금은 다르다". 하야카와 전화: 거절할 생각이었으나 에토가 보낸 압력 곡선이 자기가 3년 계산한 논문 곡선과 거의 같은 모양 → "한 번만 그 손가락을 보러"(슈이치 "일요일이어도, 회사엔 비밀로").
