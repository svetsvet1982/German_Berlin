- S2 1부 2화(2030/1/15~25): 가사이 칩 10개 직접 지참(시제품 1개 20만 엔, 8mm 각, 한 면에 구리 전극 1만 개). 겐 씨 확대경 「銅が、島のように、浮いてるな。灰色の、海の、中に」(절연막=유리 친척). 첫 연마: 절연막 0.3nm·구리 12nm 패임(디싱). 하이브리드 본딩은 구리가 약 2nm 패여 있는 게 좋음(절연막끼리 상온 접착 → 가열로 구리 팽창해 틈 메움), 「へこみすぎても、だめ…でっぱっても、だめ」. 힘으로는 둘 다 못 세움 → 연마액 화학(구리 보호막 약품) → 슈이치 "구리를 붙이는 게 도금, 깎는 게 연마, 같은 구리 얘기" → 미요시 도금 사카모토(64)·다쿠미(25) 「抑制剤」, 선대 미요시 사장 칠판 배합에 온도별 억제제 표(30년 전), "구리 화학은 온도로 전부 바뀐다"(작년 여름 73번 3도 실패), "논문 쓰는 사람은 도금 조 앞에 서 본 적이 없다". 구리판·유리판으로 먼저 20조건(온도 5×약품 4) → 25도·약품 3번째: 구리 2.1nm·절연막 0.3nm(도금 표와 같은 온도). 다쿠미 "온도계 두 개". 가스가 입사 4년째(슈이치 '재미있다' 얼굴에 이미 전화). 겐 씨 "작은 건 팔꿈치보다 손가락, 손가락 바닥으로 쓰다듬어라, 누르지 마". 칩 10개(란 5·겐타 5) 평균 2.2nm, 겐타 쪽 가장자리 패임 적음. 5쌍 접합(위치 0.2μm 이내) → 가마타 열처리 우다가와 유타카(61, 열처리 40년, 1월 네트워크 가입) 200도 2시간·±2도·승온 분당 5도(급가열 시 유리·구리 팽창 차로 깨짐), 겐 씨 「磨くより、待つほうが、難しい」. 결과: 1~3쌍 1만/1만 통전, 4쌍(란+겐타 칩) 모서리 800개 불통, 5쌍(란 칩 2개) 중앙 원형 2천 개 불통(보이드=먼지 추정) → 6할, 가사이 "양산이면 불합격(99% 필요), 첫 시제작으로는 본 것 중 최고". 원인 2개로 분리(모서리=연마, 중앙=세정) 「原因が、分かれたら、半分、解けた」. 다음: 300mm 웨이퍼(칩 900개)째 연마·접합, 클린룸, CMP 장비(대당 몇억). 겐 씨 "기계한테 손가락 바닥이 있냐" → 에토 "겐타 손가락 압력 데이터로 만들 수도" → 「なるんじゃねえ。教えるんだ」. 사카모토 도금 칠판 옆에 연마액 표 덧쓰기 → 미요시 씨 허락 먼저.
