# TOKYO 일본어 낭독 교재 — 시리즈 기획안

## 『ミクロンの矜持（きょうじ）』
**미크론의 자존심 — 가마타 작은 공장이 거대 기업과 관료 사회를 넘어서기까지**

| 항목 | 내용 |
|---|---|
| 배경 | 일본 도쿄 오타구 가마타·고지야(大田区 蒲田·糀谷) 마치코바(町工場) 거리 → 이후 홋카이도 지토세, 해외 |
| 시간 | 2026년 3월(1부) ~ 2029년 12월(5부) |
| 분량 | 5부 × 15화 = 총 75화 / 화당 대사 150턴 (총 11,250턴) |
| 형식 | 지문 없이 대사만 · 일본어 본문 + 한국어 대역 (기존 BERLIN 교재 형식과 동일) |
| 난이도 | 1부 JLPT N3 → 2부 N3~N2 → 3부 N2 → 4부 N2~N1 → 5부 N1 |
| 장르 | 기업·경제 드라마 (현실 이슈 기반, 회사·인물·사건은 모두 가상) |

> **핵심 메시지**: "가격도, 기술도, 사람도 — 남이 정하게 두지 않는다."
> 주인공은 복수가 아니라 **핵심역량(초정밀 이종재료 접합 기술 'T-BOND')** 으로 살아남고, 그 역량을 축으로 반도체 → 인재·지역 → 의료·우주·해외로 사업을 확장한다.

## 1. 세계관 · 회사 설정

**株式会社タカノ精機（タカノせいき）** — 오타구 고지야, 1971년 창업, 종업원 32명(1부 시점)
- **핵심 기술 'T-BOND'**: 금속–세라믹–수지를 접착제 없이 상온에서 나노 단위로 직접 접합하는 기술 + ±0.1μm 초정밀 연마
- **응용 경로(=사업 확장 축)**
  1. 자동차 부품 하청 (1부 시작점, 매출 40%가 대기업 1곳)
  2. 반도체 제조장비 부품 — 정전척·챔버 부품 (3부)
  3. 도금·표면처리 동료 공장 인수 → 그룹화 (4부)
  4. 의료 임플란트·인공위성 부품·해외 거점 (5부)

**적대 구조(3층)**
1. **거대 기업**: ヤマト総合重工(야마토 종합중공) — 자동차·중공업·방산 복합 대기업
2. **관료 사회**: 경제산업성(経産省) 제조산업국, 보조금·국책 컨소시엄 행정
3. **유착 고리**: 전 사무차관 출신으로 야마토 고문인 아마쿠다리(天下り) 인사
