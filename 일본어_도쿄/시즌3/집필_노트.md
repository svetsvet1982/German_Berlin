## 화별 요약
- S3 1부 1화(2031/1/6 월~1/8): 3호기 새해 인사, 겐 씨 "주축 베어링이 조금 노래한다(52년째 정월에 들떠서)" → 새것 아니라 세 번째 재연마, 「三号機の、部品は、半分、直した、物で、できてる」. 겐타 새 일지 첫 페이지에 작년 마지막 줄 「つながった」. 신년 집회: 2030 매출 24억 3천만·경상 2억 1천만·방위 0엔, 4월부터 정찰 창(2.5%). 올해 3가지: ①4/15 첫 재검토(아침 이와테·낮 이마이 맨션·밤 히사고) ②나가오카 시나노가와에 스피넬 손(내년 봄) ③「直す」年 — 연마·접합 수리점, 책임자 겐타, 사사키에게 '고친 것의 검사 기준'(4/15까지). 메구미 "고친 것은 값이 없다" → "값은 스스로 정한다(5년 전 3/12 15:40부터)". 렌(지토세 영하 9도) 2동 뒤 창고의 폐부품 산: 리테이너 링 매주 40개×순정 18만 엔(넥스트 연 3억 7천만, 다카노 2호기 몫 연 4천만=작년 이익의 5분의 1), 안쪽 1mm만 닳아도 폐기, 오와시 테크노(大鷲テクノ, CMP 장비·부품) "고리만 타사 것 쓰면 보증 소멸". 렌 원점 고백(정비 하청 "교환만 하는 손은 내 손이 아닌 것 같았다") → 「直せませんか。この、山」, 겐타 "제일 닳은 거 하나 보내". 란 "버리는 거라도 넥스트 것, 먼저 말해(3조)" → 사나다에게 전화, 렌 「捨てる、記録」 첫 줄. 3호기: 주축 커버(예비는 1979 히무로 주조, 달린 건 첫 커버—세 번 용접·연마), 베어링 3회, 이송 나사 2회, 공구대는 선대가 도면 없이 다시 만듦(지금은 겐 씨 손 안 → 올해 겐타에게). 선대 시절 검사는 선대의 「よし」 → "남의 걸 고치면 '됐다'의 내용을 종이에", 사사키 「新品は、生まれた、時の、検査。直した、物は、残りの、人生の、検査」("앞으로 얼마나 쓸 수 있나"). 3호기 베어링을 1/20(토) '고치는 일 첫 번째'로(선대 「自分の、機械を、直せねえ、やつに、人の、部品は、作れねえ」), 겐 씨 이번엔 입도 댐, 손은 겐타. 집: 미사키(28, 보육교사), 유이 딸랑이 금 → 홈을 깎아 다시 끼움(소리 안 바뀌게, 유이가 기억), 일지 「直す、仕事、一本目。結の、ガラガラ」.
- S3 1부 2화(2031/1/9 목~1/17 금): 리테이너 링(PPS 수지, 직경 300mm 웨이퍼용) 도착 — 렌 메모 '사용 400시간, 2호기 두 번째 대'. 아래 면 방사형 홈 24줄, 새것 깊이 3mm → 1.9mm(아래 면 1mm 마모), 두께 20mm라 재연마+홈 재가공으로 3회 더 사용 가능(계산). 36군데(10도 간격) 측정: 210도 1.3mm 최대·30도 0.7mm 최소 → 헤드 기울어짐 '가능성'(사사키 「たぶん」은 검사 말이 아니다, '가능성이 있다' 다음엔 '확인한다'가 온다). 겐 씨 「すり減り方は、手紙だ」(3호기 베어링=50년 편지), "고리 고치기 전에 기계를 고친다 = 진짜 고치는 일". 지토세 라멘집(된장, 오쓰카는 버터): 렌 옛 동료 오쓰카 쓰바사(27, 정비 하청 「北斗メンテック」, 렌을 세 번 말렸고 네 번째에 그만둠) — 화 링·목 막·금 패드 교환, 회사는 교환 1회당 매출이라 오래 쓰면 손해, "그때 '풋내 난다' 생각, 지금도 조금, 하지만 조금 부럽다", 석 달 전부터 2호기 두 번째 대 헤드가 기울어 한쪽만 가루 많음 → 위에 말했지만 "주기는 지킨다, 문제없다" → 세 번째부터 말 안 함. 이름 빼고 기록에 씀. 손 기록과 마모 일치(사사키 "둘이 맞으면 일단 믿어도 된다"). 첫 재생: 제일 상한 210도에 맞춰 전체 1.3mm 깎아 평탄화(「直す、時は、一番、傷んだ、ところに、合わせる」), 홈 깊이 3mm·모서리 R0.2(새 순정 링 48군데 측정 기준), 아래 면 2시간·홈 4시간 → 두께 18.7mm·편차 0.02(새것 0.05보다 좋음), 홈 3.00·R0.20. 하지만 '남은 인생'은 써 봐야 앎. 사나다: 넥스트–오와시 보수 계약 제8조 「純正部品以外の、部品を、使用した、場合、装置の、保証は、その、時点で、失効する」(장치 한 대 40억 엔), 법무로선 '그만두라', 개인으론 "연 3억 7천만 엔 버리는 건 바보 같다", "제8조는 다카노 씨 숙제(숙제는 대개 옳은 사람한테서 온다)". 가마타 2호기도 오와시 제품, 3호기는 선반이라 CMP 아님.
