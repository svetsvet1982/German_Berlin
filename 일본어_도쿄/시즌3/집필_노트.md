- S3 1부 2화(2031/1/9 목~1/17 금): 리테이너 링(PPS 수지, 직경 300mm 웨이퍼용) 도착 — 렌 메모 '사용 400시간, 2호기 두 번째 대'. 아래 면 방사형 홈 24줄, 새것 깊이 3mm → 1.9mm(아래 면 1mm 마모), 두께 20mm라 재연마+홈 재가공으로 3회 더 사용 가능(계산). 36군데(10도 간격) 측정: 210도 1.3mm 최대·30도 0.7mm 최소 → 헤드 기울어짐 '가능성'(사사키 「たぶん」은 검사 말이 아니다, '가능성이 있다' 다음엔 '확인한다'가 온다). 겐 씨 「すり減り方は、手紙だ」(3호기 베어링=50년 편지), "고리 고치기 전에 기계를 고친다 = 진짜 고치는 일". 지토세 라멘집(된장, 오쓰카는 버터): 렌 옛 동료 오쓰카 쓰바사(27, 정비 하청 「北斗メンテック」, 렌을 세 번 말렸고 네 번째에 그만둠) — 화 링·목 막·금 패드 교환, 회사는 교환 1회당 매출이라 오래 쓰면 손해, "그때 '풋내 난다' 생각, 지금도 조금, 하지만 조금 부럽다", 석 달 전부터 2호기 두 번째 대 헤드가 기울어 한쪽만 가루 많음 → 위에 말했지만 "주기는 지킨다, 문제없다" → 세 번째부터 말 안 함. 이름 빼고 기록에 씀. 손 기록과 마모 일치(사사키 "둘이 맞으면 일단 믿어도 된다"). 첫 재생: 제일 상한 210도에 맞춰 전체 1.3mm 깎아 평탄화(「直す、時は、一番、傷んだ、ところに、合わせる」), 홈 깊이 3mm·모서리 R0.2(새 순정 링 48군데 측정 기준), 아래 면 2시간·홈 4시간 → 두께 18.7mm·편차 0.02(새것 0.05보다 좋음), 홈 3.00·R0.20. 하지만 '남은 인생'은 써 봐야 앎. 사나다: 넥스트–오와시 보수 계약 제8조 「純正部品以外の、部品を、使用した、場合、装置の、保証は、その、時点で、失効する」(장치 한 대 40억 엔), 법무로선 '그만두라', 개인으론 "연 3억 7천만 엔 버리는 건 바보 같다", "제8조는 다카노 씨 숙제(숙제는 대개 옳은 사람한테서 온다)". 가마타 2호기도 오와시 제품, 3호기는 선반이라 CMP 아님.
- S3 1부 3화(2031/1/18 토~1/24 금): 1/20(토) 3호기 정지(평소 토요일도 돌림), 겐 씨는 입만·손은 겐타. 주축 커버 볼트 6개 대각선 반 바퀴씩(커버는 세 번 용접, 두 번째는 선대가 떨어뜨려서). 앞쪽 베어링 내륜 궤도: 회전 방향 줄(보통 마모) + 한 군데 폭 5mm 흐림(깊이 2μm, 다른 곳 0.5) = '노래'의 정체 → 2030/12/20 21:12 낙뢰 정전 급정지 때 볼 충돌 자국(일지 '이상 없음'은 그날 얘기, 한 달 걸려 노래 시작). 내륜 전체 2μm 다듬기(제일 상한 곳에 맞춤), 볼은 교체(둥근 건 둥근 채로 닳아 판별 불가, 로쿠고 볼 가게 50년) → 사사키 검사 기준 첫 줄 「直す、部分と、替える、部分を、書く」. 재조립 후 노래 멈춤, 진동 0.3 감소. 일지 「一月、二十日。三号機、ベアリング、三回目。歌、止まる。……二本目」「源さん、口だけ。手は、出さず」(첫 번째는 유이 딸랑이 — 미사키→시즈에→겐 씨로 전파). 지토세 다카노 2호기(오와시, 첫 대 2030/6 도입·보증 5년·4억 엔) 보증서 제12조 「純正部品以外の、部品、または、消耗品を、使用した、場合…本装置の、全部に、ついて、保証の、責任を、負わない」 → 구가: '전부'가 걸린다, 독점금지법 끼워 팔기·구속 조건부 거래, 해외 수리할 권리, 일본은 논의 중, 싸움은 최후 — 먼저 오와시 현장 사람에게 '왜 전부인가'를 묻는다. 렌의 '2호기 두 번째 대 설치 일지'(2030/8/18): 「ヘッド、右に、〇・〇三度？ ……北斗の、人、『規格内』。……手で、触ると、右が、少し、低い、気が、する」「気の、せい、かも。書いて、おく」 → 오와시 규격 0.05도 이내, 0.03도 = 300mm 끝 차 0.16mm, 링 마모 차 0.6mm/400h와 맞음. 설치 일지·오쓰카 가루·링 마모 셋이 맞음. 겐 씨 "네 손은 8월에 이미 알았다, 머리가 손을 안 믿었을 뿐" / 「書いたやつが、一番、えらい」. 슈이치: 고리 얘기 말고 기울기 얘기부터 넥스트·오와시에(순정 고리 수명도 늘어 오와시 고리가 덜 팔려도), 구가가 싸움 안 되는 말투 담당, 렌 동행("손으로 만진 사람으로서").
- S3 1부 4화(2031/1/28 화~2/4 화): 넥스트 새 CTO 이소베 가쓰미(52, 가사이 후임, 전 회사 공장 원가 담당 '숫자 쪽 사람'). 기울기 0.03도 보고 → "규격 내면 문제없다" → 숫자 제시(36군데·설치 메모·오쓰카 가루) → 겐타 계산: 기울기 고치면 수명 400→550h(1.4배, 30도 마모 속도로 전체 감소) → 연 3억 7천만 → 2억 6천만(1억 1천만 절약), 기울기 조정은 오와시 보수 범위(무료). 메구미 원가: 재생 1개 원가 2만 8천(연마 2h·홈 4h·검사 1h), 3회 재생 가능 → 새것 1개를 4번 사용, 판매가 5만(이익률 44%) / 순정 원가 추정 5만(PPS 재료 2만+성형·가공 3만, 가마타 수지 가게 견적) 판매 18만(72%).
